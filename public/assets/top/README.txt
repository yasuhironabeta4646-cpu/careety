# Careety TOP素材セット

## 写真
photos/ にPNG（元画像を保持したロスレス）とJPEG（品質95、Wix用）を6点ずつ収録。
- 01：ヒーローの女子大学生、1536×1024px。
- 02：大学生グループ、1536×1024px。
- 03〜06：記事用の大学生・ワークシート・面接・街並み、各768×512px。
原画像の解像度を保持し、引き伸ばしやAIアップスケールはしていません。すべてAI生成イメージであり、実在の社員・利用者を撮影した写真ではありません。

## ベクター
vectors/ に13カテゴリーのアイコン、学年別の4人物イラスト、資料4アイコン、UIアイコン、ヒーロー背景のグラデーションをSVGで収録。背景が透明なSVGはWixへそのままアップロードするか、Figmaで配置して必要なサイズに書き出せます。Lucide由来のアイコンのライセンスをLUCIDE-LICENSE.txtに同梱。

## ロゴ・文字
brand/ の仮文字ロゴは実装のNoto系フォントをアウトラインにしたSVG。正式ロゴではありません。正式なC＋顔のブランドマークは未提供のため含みません。フォントはNoto Sans JP系。フォントの設定値とOFLを同梱しています。
見出し・タグ・ボタンの文言は、画像に焼き込まずFigma/Wixでテキストとして配置してください。

## Wixでの再現
specs/ にデザイン仕様、全体CSS、共通ブランドCSS、ヒーローのPC表示位置、写真の解像度と用途を同梱。色、余白、角丸、影、ボタンは基本的にWixの要素設定で再現するため、個別の画像素材は存在しません。
ヒーローは原画像を配置したうえで、切り抜き位置と半透明の淡青グラデーションを重ねて再現します。写真そのものに文字・タグ・背景の色は合成されていません。

## ダウンロード資料
TOPの資料ボタンのPDF/Word/Excelは public/downloads の既存ファイルから利用してください。このZIPは写真・図形・デザイン仕様の素材集です。
