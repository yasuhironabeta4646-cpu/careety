# Careety Design System v2（採用ビジュアル案）

全8ページに共通の仕様。正式ロゴは未提供のため文字ロゴを仮使用。ブランドマークの模倣はせず、提供後に共通Logoコンポーネントで差し替える。

- 基本色：Brand #0158C2、CTA #0877ED、Navy #1B2232、本文 #596579、補助 #8A96A8（通常文字にはコントラスト確保のため濃い補助色を使用）、Light Blue #EFF7FE、Very Light Blue #F7FBFF、Border #DDECF8、Ivory #FFF9EE、White #FFFFFF。
- アクセント：Pink #FF8292、Orange #FF8A3D、Yellow #F6B91A、Green #16B86A。カテゴリーアイコン・小さなラベルだけに使用。
- フォント：Noto Sans JP、見出し700〜900／本文400〜500。Klee Oneは任意のアクセントのみ。本実装はNoto Sans CJK JP（日本語フェイス）をローカル配信。サンプルで使用する文字をサブセット化し、Regularを400/500、Boldを700/900に割り当てる。新しい記事を追加する際は再生成またはフルのNoto Sans JPへ切替。
- 最大幅：1200px、左右余白PC 40px・モバイル20px。記事本文最大780px（タブレット以下720px）。
- グリッド：PC 12列相当、記事一覧3列、TOP新着4列、カテゴリー4列。タブレット2列、スマホ記事1列・カテゴリー2列。
- 余白：4/8/12/16/24/32/48/64/80/96px。セクション間PC 80〜96px・スマホ56px。
- Header：高さ78px（スマホ72px）、白、文字ロゴ、5主ナビ、検索。モバイルはメニューボタン。全ページ共通。
- Footer：淡いブルー、ブランド説明・情報探索・メディア情報・法務リンク。全ページ共通。
- Button：角丸24px、高さ48px以上。主CTAは青、補助は白＋ボーダー。文字リンクは矢印つき。
- Article Card：写真約1.65:1、白、角丸10px、薄い境界線、カテゴリー・タイトル・日付。共通カードをすべてのページで使用。
- Category Card：アイコン、タイトル、短い説明、矢印。角丸12px、薄い境界線。
- Download Card：用紙のイラスト、ファイル形式、説明、直接ダウンロード。
- CTA：内容探索を優先。LINEは下部。エージェントは解説を経由し広告関係を明示。
- Careety POINT：淡いブルー背景、青の左境界線、ブランド名、短い要点。記事内のみ。
- タグ：淡い背景、角丸4px、12px文字。色だけで意味を示さない。
- 見出し：英語ラベル12px・日本語見出し28〜36px。ページタイトル40px、記事見出し28px、本文16〜17px・行高1.9〜2。
- 写真：自然光・大学生活・青とアイボリーの穏やかなトーン。仮のAI生成写真であり実在のスタッフ等を表さない。
- 動作：過剰なアニメーションなし。focus-visible、キーボード操作、減速設定、ラベル、エラー／結果の通知を共通にする。

Wixでは共通セクション・リピーター・データセット・動的ページで再現。ページ固有のデザイントークン変更は禁止。

## 採用された写真主体の共通仕様

TOPは写真主体のVisualHomeを正式採用。すべての記事カードをPhotoArticleに統合し、記事詳細も同じカテゴリーに対応する写真を表示。下層の導入は共通PageHeading（淡青の文章＋右の写真、スマホでは写真→文章）を使用。資料は用紙のイラスト、学年ガイドは人物の線画で補助。問い合わせはフォームを中央780pxに置くが、ページ外側は同じ1200pxコンテンツ幅を使う。エージェント解説は共通写真と情報カードを使用し、架空の提携先は掲載しない。

/ のTOPが採用案、/top-visual は互換URL、/top-classic は旧レイアウトの参考ページ。主要8ページのナビゲーションは採用案を起点にする。検索・色・アイコン・Button・Header・Footer・Careety POINTの共通仕様を保つ。CMSのフィールドと8ページ構成は変更しない。
